<h3>💜 Sobre mí</h3>

<p>Soy <b>Juan Esper</b>, enfocado en el Análisis y Desarrollo de Software, y me apasiona convertir ideas en productos digitales útiles y bien elaborados.</p>

<p>Tengo experiencia construyendo servicios backend y APIs con <b>Python y FastAPI</b>, así como configurando servidores proxy y entornos de desarrollo. En el frontend, trabajo creando interfaces estructuradas, aplicaciones web progresivas (PWA) y layouts dinámicos.</p>

<p>En este momento estoy perfeccionando mis habilidades full-stack integrando tecnologías como <b>Django, SQL, Java, PHP y JavaScript</b>. Aprendo mejor construyendo, y cada proyecto es una oportunidad para experimentar con algo nuevo.</p>

<p>Desarrollé y desplegué una aplicación web progresiva de streaming de audio en <b>Vercel</b>.<br>
